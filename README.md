# PayReady

PayReady ayuda a elegir, integrar y probar pasarelas de pago en proyectos de software. Incluye un catálogo de proveedores, plantillas de integración y validadores para revisar el checkout y las notificaciones.

| Edición | Instalación | Uso |
| --- | --- | --- |
| Claude Code | [Guía](docs/guia-claude.md) | `/payready:start` |
| Codex | [Guía](docs/guia-codex.md) | `$payready` |

Claude Code conserva los comandos y hooks nativos del plugin. Codex usa una skill instalable y ejecuta el mismo motor mediante comandos de validación explícitos.
